# Лабораторная работа №2 — Вариант 13

## Задание

1. **Массивы:** объединить несколько массивов в один с сохранением уникальных значений.
2. **SPL:** реализовать бесконечный итератор через `InfiniteIterator` на основе `ArrayIterator`.
3. **HTML/CSS/PHP:** список `<ul>`, у которого размер шрифта пропорционален длине строки.

## Требования

- PHP ≥ 8.0 (используется `declare(strict_types=1)`, `mb_*`, SPL-итераторы).
- Любой веб-сервер с PHP (Apache + mod_php, Nginx + PHP-FPM, встроенный сервер PHP).

## Запуск

### Вариант 1: встроенный сервер PHP

cd lab_2
